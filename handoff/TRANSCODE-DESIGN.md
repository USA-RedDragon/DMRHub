# Codec2 <-> AMBE transcoding: owner decisions (2026-10-23, US Central)

- Default: every repeater slot is AMBE. A slot is Codec2 when a voice call from it has a Voice LC header with a valid CRC and FID 0xC2. Never infer Codec2 from voice bits or padding (no false positives). Per call, the source codec is the FID of that call, so Codec2 arriving from network peers (OpenBridge) is recognized too.
- Flag scope: per repeater, per slot (most flexible). Network peers (OpenBridge, IPSC) are AMBE-only targets.
- Flag lifetime: sticky and saved in the DB. An AMBE call from that slot clears it. Admins also get a per-slot setting: Auto (default), Codec2, AMBE. The setting overrides detection.
- Delivery: AMBE call to a Codec2 slot is transcoded to Codec2. Codec2 call to an AMBE-only target is transcoded to AMBE. Same codec on both ends: passthrough unchanged. Transcode once per call stream and direction, shared by every target that needs it.
- AMBE: an AMBE server over UDP (dmrgo vocoder/dvsi, AMBEserver protocol, port 2460). One configured address, editable by admins in the Setup UI. Assume it scales without limit and fails only when far overloaded or down.
- Codec2: dmrgo vocoder/codec2 WASM backend (wazero), no cgo. DMRHub stays CGO_ENABLED=0.
- Failure: retry. A failed frame request is retried within the burst's time budget. While the server is unreachable, keep retrying on the next bursts and resume transcoding mid-call. Audio missed meanwhile is counted (metric with reason) and marked on the last-heard row. Never hold or queue audio (owner: no stalls).
- Codec2 mode for output to a Codec2 slot: the mode last detected from that slot (2400 default, QRadioLink default).
- Minimize transcoding: at most once per call. One transcode per stream and direction, shared by all targets that need it. Targets on the caller's codec always get the original bits. Never transcode a stream that is itself a transcoded copy (parrot, IPSC fan-out, loops work from the original). Open owner question for later: a per-peer OpenBridge option to send the original Codec2 to peers that can carry it (avoids a second transcode at another DMRHub; risk: AMBE-only networks behind that peer get Codec2).
- Owner 2026-10-23: OpenBridge peers get an admin setting "Codec2 support", off by default. Off: the peer is AMBE-only, Codec2 calls reach it transcoded to AMBE (once). On: the peer gets every call in its original codec (Codec2 as Codec2, AMBE as AMBE), never transcoded by us. IPSC peers are always AMBE-only, no setting. The setting is on the existing OpenBridge peer edit form. A second transcode at another hub is accepted.
